# Commit

コミット前提

- verifier成功
- コミット対象（`git status`・ステージ済み差分）に、今回の変更と無関係で、かつコードから参照されないファイル（バイナリ、一時ファイル等）が含まれていないかを確認する。意図的にリポジトリへ追加する資産ファイルである場合を除き、該当するファイルはコミットから除外する
- ステージ済み差分に実在の個人情報（氏名・生年月日・住所・電話番号・学校名・勤務先・医療情報等）がハードコードされていないか確認する。個人情報を扱うプロダクトの詳細な原則は`docs/public-repo-no-pii-pattern.md`を参照。個人情報を削除・汎用化する変更の場合、コミットメッセージ本文に削除対象の実際の値そのものを書かない（カテゴリ・件数のみにとどめる。同文書参照）
